**⚽ GameBola**



A \*\*3D football game\*\* developed using \*\*Unity\*\* and \*\*C#\*\*.



This project focuses on creating a simple interactive football game experience using Unity's 3D game development features.





🎮 **Game Overview**



GameBola is a standalone Windows game featuring a 3D football gameplay environment.



The project was developed as part of a game development project to practice Unity, 3D game mechanics, and standalone game deployment.







**✨ Features**



\* ⚽ 3D football gameplay

\* 🎮 Interactive game environment

\* 🏟️ 3D game scene

\* 🖥️ Windows standalone build

\* 🎯 Unity-based gameplay







**🛠️ Tech Stack**



\* \*\*Game Engine:\*\* Unity

\* \*\*Programming Language:\*\* C#

\* \*\*Project Type:\*\* 3D Football Game

\* \*\*Platform:\*\* Windows

**🎮 How to Play**



**Windows**



1\. Download or clone this repository.

2\. Keep all files in the same directory.

3\. Run:



```text

GameBola.exe

```



> **Important:** `UnityPlayer.dll`, `UnityCrashHandler64.exe`, and `WinPixEventRuntime.dll` are required runtime files. Do not remove them from the game folder.
